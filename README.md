# Custom Wraith Codes

Custom Wraith Codes is a Geode mod for Geometry Dash that allows players to add custom redeemable codes to the Wraith Vault.

This repository contains an updated version maintained for Geometry Dash / Geode version **2.2081**.

## Usage
1. Open the Wraith Vault in-game.
2. Enter the code: `kale`.
3. Claim the reward.

The default code, rewards, and parameters can be configured through the mod settings menu.

## Building from Source

### Prerequisites
Ensure the following dependencies and tools are installed:
- **CMake**
- **MSVC** or **Clang**
- **Git**
- **Geode CLI**
- **Geode SDK**

### Compilation
```bash
git clone [https://github.com/nostraxiten/CustomWraithCodes.git](https://github.com/nostraxiten/CustomWraithCodes.git)
cd CustomWraithCodes
geode build
